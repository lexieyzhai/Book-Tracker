# Book Tracker GitHub Pages Version

Upload this folder to GitHub Pages.

The app is a single static `index.html` file. People who open the finished website do not need a GitHub account.

Data saving:

- Saves ratings, finished status, notes, custom books, deleted books, deleted series, and timer settings in the browser on that device.
- A phone and computer save separately.
- Data stays saved when the page is reopened, unless that browser's site data is cleared.

Simple publish steps:

1. Make a free GitHub account, or use an existing one.
2. Create a new public repository named `book-tracker`.
3. Upload `index.html`, `.nojekyll`, and this `README.md`.
4. Open the repository settings.
5. Go to Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch `main` and folder `/root`.
8. Save.

After GitHub finishes publishing, the site link will look like:

`https://YOUR-USERNAME.github.io/book-tracker/`
